# References

Work this library builds on or is compared against. The code was written from the definitions in these sources and from bitdp's kernels, not from any existing implementation.

## Papers

- S. Bae, J. Park, J.-S. Kim. Cas-OFFinder: a fast and versatile algorithm that searches for potential off-target sites of Cas9 RNA-guided endonucleases. *Bioinformatics* 30(10):1473–1475, 2014. doi:10.1093/bioinformatics/btu048. The reference off-target search that variant-aware tools extend.
- G. Myers. A fast bit-vector algorithm for approximate string matching based on dynamic programming. *Journal of the ACM* 46(3), 1999. doi:10.1145/316542.316550. Bit-parallel search, the basis of the scan.
- H. Hyyrö, K. Fredriksson, G. Navarro. Increased bit-parallelism for approximate and multiple string matching. *ACM Journal of Experimental Algorithmics* 10, 2005. doi:10.1145/1064546.1180617. Several short patterns in one word.
